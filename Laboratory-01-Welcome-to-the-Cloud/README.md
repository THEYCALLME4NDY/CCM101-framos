# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduces the basic skills required for working with cloud infrastructure and Linux environments. The activity was completed using the KillerCoda Linux Playground.

## Objectives

- Access a cloud-based Linux environment.
- Explore and navigate Linux.
- Gather basic system information.
- Create and organize files and directories.
- Document technical work using Markdown.
- Prepare a GitHub Cloud Computing portfolio.

## Activities Performed

- Accessed Ubuntu 24.04 through KillerCoda.
- Created and logged in to a Linux user account.
- Checked the username, working directory, and hostname.
- Gathered Linux system information.
- Created and organized directories and Markdown files.
- Prepared the laboratory documentation for GitHub.

## Linux Commands Used

- `whoami` – displays the current username.
- `pwd` – displays the current working directory.
- `hostname` – displays the hostname.
- `cd` – changes the current directory.
- `mkdir` – creates directories.
- `touch` – creates files.
- `cat` – displays file contents.
- `ls` – lists files and directories.
- `nano` – edits text files.
- `useradd` – creates a Linux user.
- `passwd` – sets a user's password.
- `su` – switches to another user.

## Skills Learned

I learned how to navigate a Linux environment, manage a Linux user account, gather system information, organize files and directories, and document technical activities using Markdown and GitHub.
