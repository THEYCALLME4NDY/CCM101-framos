# Reflection

## What I Learned

In this laboratory activity, I learned how to access and use a Linux environment through the KillerCoda Playground. I practiced basic Linux commands for navigating directories, creating files, managing users, and checking system information.

I also learned how to organize technical files and document my work using Markdown.

## Challenges Encountered

One challenge I encountered was learning the correct Linux commands and understanding the required directory structure. I also experienced the temporary nature of the KillerCoda Playground, which taught me the importance of keeping important work in a permanent version-controlled repository.

## What I Gained

This activity helped me become more comfortable with the Linux command line and introduced me to GitHub as a version-controlled portfolio for cloud computing activities.

Overall, I learned that proper documentation, organization, and version control are important skills for a cloud infrastructure engineer.
