## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest cloud service portfolios and has a very mature ecosystem. It provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. Organizations already using Windows Server, Microsoft 365, Active Directory, and other Microsoft products can use Azure services to extend their existing environment into the cloud.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in artificial intelligence, machine learning, and Kubernetes. Its Google Kubernetes Engine and broad AI and data services make it a strong choice for organizations developing AI and containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a broad range of services and supports many different types of applications. Its extensive ecosystem also provides opportunities to learn different cloud technologies and develop skills that can be useful in cloud infrastructure careers.
