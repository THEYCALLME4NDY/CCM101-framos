# Mission 3 Reflection

Completing Mission 3 helped me understand that AWS, Microsoft Azure, and Google Cloud Platform are powerful cloud providers, but each one has different strengths. The cloud platform that impressed me the most is Google Cloud Platform because of its strong capabilities in Artificial Intelligence, Machine Learning, data analytics, and Kubernetes. I found these technologies interesting because they are becoming increasingly important in modern software development and cloud computing.

AWS, Azure, and GCP have many similarities. All three provide services for computing, storage, databases, networking, security, identity management, containers, and monitoring. They also provide management consoles where users can create, configure, and monitor cloud resources. Although their services have different names, many of them provide similar functions, such as AWS EC2, Azure Virtual Machines, and Google Compute Engine.

Business requirements have a major influence on cloud platform selection. A company should consider its budget, existing technologies, performance requirements, security needs, scalability, location, and future plans. For example, a university that already uses Windows Server, Microsoft 365, and Active Directory may benefit more from Azure, while an AI research company may prefer Google Cloud because of its AI and machine learning capabilities.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. I learned that I need to understand the client's actual requirements and compare different services before making a recommendation.

My GitHub Cloud Computing Portfolio also improved after completing this mission. I learned how to organize technical information using Markdown, create comparison tables, document cloud research, and maintain screenshots as evidence. Overall, this mission improved my understanding of multi-cloud environments and helped me think more like a Cloud Solutions Consultant.
